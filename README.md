# tv-live

央视 1-17 + 卫视 直播源（中国大陆直连）。

- `cctv.m3u` — 央视 1-17（18 台，每台 3 条，H.264 1080p）
- `ws.m3u` — 卫视（34 台，85 条；辽宁/新疆/广西各 1 条稳定线，其余 2-3 条）
- `ok-cctv.json` — OK影视 / TVBox 配置（两个分类：央视 1-17、卫视）

## 配置地址（中国大陆直连）

```
https://gh-proxy.com/https://raw.githubusercontent.com/TuTu123471/tv-live/main/ok-cctv.json
```

## 自动维护

腾讯云函数 `iptv-refresh` 每天 04:00（北京时间）维护 `cctv.m3u`：

- 只替换连续两次都测不通的死线
- 替换源只用抽帧验证过的同频道源
- 找不到验证过的备源就保留原线，绝不删除
- 移动 CDN / 浙江广电 CDN 的线不探测、不改动

`ws.m3u` 是抽帧验证 + 真实分片测速后的静态版，目前不由云函数自动修改。
